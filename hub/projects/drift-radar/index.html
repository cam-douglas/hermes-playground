Drift Radar

Catch drift before the loop turns into a dead end.

A local-first recovery console for autonomous work. It tracks what the agent intended, what actually happened, which blocker is in the way, and the safest next move before the run wastes more time.

Open dashboard Add a run step Back to catalogue

Problem

Agents have plenty of forward motion, but weak recovery. When they stall, humans need a clean view of drift and blocker type.

Users

Supervising operators, coding agents, support teams, and anyone running long tasks that need a restart plan.

Workflow

Record the intended step, classify the blocker, rank recovery priority, then choose continue, reframe, escalate, or reset.

Product notes

Architecture: static HTML/CSS/JS, no backend, local persistence. Data model: objective, observed state, blocker type, owner, confidence, and drift score. Deployment: ship to Vercel as a self-contained product folder.
