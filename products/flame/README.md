# Flame

A board looks even until you see the flame. Move the figure. See the leftover leap.

This is not Curl. Curl is leftover undulating wave-figure / fiddleback running across the face. This is not Crotch. Crotch is leftover feather/plume at a trunk/limb fork. This is not Ribbon. Ribbon is leftover vertical quartered stripe-bands of grain. This is not Quilt. Quilt is leftover 3D blister-patches / quilted maple balloons. This is not Mottle. Mottle is leftover broken blotch-patches of figure. This is not Drip. Drip is leftover liquid run on the face (a bead, a tail, a puddle). This is not Throw. Throw is leftover vent plume reach in air. This is not Ridge. Ridge is leftover roof peak where two planes meet. This is not Kelvin. Kelvin is leftover lamp warmth. This is not Grain. Grain is leftover mismatch of the cut to the fibres. This is not Fold Sheet. Fold Sheet is leftover paper creases. This is not Burl. Burl is leftover swirl occupying a patch. This is not Eye. Eye is leftover tiny circular bird's-eye dimples. This is not Stain. Stain is leftover color wash. This is not a paste well. This is not a clock. Flame answers “how far the leftover leap still sits in the figure.”

## Problem

A board looks even until you see the flame:

- how far does the leftover leap still sit in the figure?
- is the leftover even, or showing?
- when is the leftover flame obvious — as a sketch, not a mill sign-off?

## Users

- people who already know a board can look even until the leftover leap shows
- anyone who refuses to treat a curl wave, a crotch plume, a ribbon stripe, a packed sky, or a clock as this leftover
- desks that want flame as a sketch, not a mill sign-off
- teams that want a no-backend, local-only pass — not Curl, not Crotch, not Drip, not a paste well

## Workflow

1. Load the seed: 34 mm of leftover flame — already showing, not an even-only face
2. Read the scene: one board in face, a leftover whose leftover is the flame, leftover labelled as a sketch
3. Move flame (or use the arrow keys on the focused slider); leftover names showing or even
4. Drop the leftover toward 0 mm and the board looks even / no leftover flame; raise it and taller leftover leaping peaks still sit in the face
5. Reset restores the seeded leftover showing

## Data model

One board in face with leftover flame as leftover leap that still sits in the figure:

- `flame` — millimetres of leftover leap showing (default 34)

Derived picture:

- leftover labelled as a sketch (even / showing), not a mill sign-off
- leftover leap labelled as a sketch
- even / no leftover flame when flame ≤ 4 mm (the board looks even throughout)

Nothing is persisted. Refresh restores the seeded scene.
