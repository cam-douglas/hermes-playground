# Crotch

A board looks even until you see the crotch. Move the figure. See the leftover plume.

This is not Crook. Crook is leftover edge sweep in plan — a curve of the board's edge. This is not Burl. Burl is leftover swirl of figure from a dormant bud occupying a patch. This is not Ribbon. Ribbon is leftover vertical quartered stripe-bands. This is not Curl. Curl is leftover wave / fiddleback figure running across the face. This is not Quilt. Quilt is leftover blister-patches of figure. This is not Eye. Eye is leftover tiny circular bird's-eye dimples. This is not Ray. Ray is leftover medullary flash / spoke from pith toward bark. This is not Ring. Ring is leftover annual year-band that still sits in the face. This is not Stain. Stain is leftover grey-blue mineral/blue-stain wash. This is not Sap. Sap is leftover pale edge band of sapwood on a heartwood face. This is not Heart. Heart is leftover inner that still occupies the core as a darker heartwood zone down the middle. This is not Knot. Knot is leftover circular dark of branch wood / pith. This is not Grain. Grain is leftover mismatch of the cut to the fibres. This is not Fold Sheet. Fold Sheet is leftover paper creases. This is not Spalt. Spalt is leftover dark wandering zone-lines. This is not Pitch. Pitch is leftover resin / gum pocket. This is not Check. Check is leftover drying split. This is not a paste well. This is not a clock. Crotch answers “how far the leftover plume still sits in the crotch.”

## Problem

- how far does the leftover plume still sit in the crotch?
- is the leftover even, or showing?

## Users

- people who already know a board can look even until the leftover plume shows
- anyone who refuses to treat a crook edge-sweep, a burl swirl, a ribbon stripe, a curl wave, a quilt blister, an eye dimple, a ray spoke, a year-band, a stain wash, a sap edge-band, a heartwood core, a knot, a packed sky, or a clock as this leftover
- desks that want crotch as a sketch, not a mill sign-off
- teams that want a no-backend, local-only pass — not Crook, not Burl, not Ribbon, not a paste well

## Workflow

1. Load the seed: 36 mm of leftover crotch — already showing, not an even-only face
2. Read the scene: one board in face, a leftover whose leftover is the crotch, leftover labelled as a sketch
3. Move crotch (or use the arrow keys on the focused slider); leftover names showing or even
4. Drop the leftover toward 0 mm and the board looks even / no leftover crotch; raise it and a larger leftover plume still sits in the face
5. Reset restores the seeded leftover showing

## Data model

One board in face with leftover crotch as leftover plume that still sits in the crotch:

- `crotch` — millimetres of leftover plume showing (default 36)

Derived picture:

- leftover labelled as a sketch (even / showing), not a mill sign-off
- leftover plume labelled as a sketch
- even / no leftover crotch when crotch ≤ 4 mm (the board looks even throughout)

Nothing is persisted. Refresh restores the seeded scene.
