# Fox

A tenon looks loose until you see the fox. Move the wedge. See the leftover flare.

This is not Drawbore. Drawbore is leftover offset that still sits through a joint — two holes slightly offset so a peg can draw the joint home. This is not Tenon. Tenon is leftover tongue that still projects from a mate. This is not Spline. Spline is leftover key that still sits between two grooves. This is not Kerf. Kerf is leftover blade path — the gap the blade removed. This is not Dowel. Dowel is leftover pin that still sits through a join. This is not Dogbone. Dogbone is leftover round relief that still sits in a corner. This is not a cut-list. This is not a paste well. This is not a clock. Fox answers “how much leftover hidden wedge still sits in the tenon.”

## Users

- people who already know a tenon can look loose until the leftover hidden wedge shows in the kerf
- anyone who refuses to treat a drawbore offset, a tenon tongue, a spline key, a kerf-only blade path, a dowel pin, a packed sky, or a clock as this leftover
- desks that want fox as a sketch, not a mill sign-off
- teams that want a no-backend, local-only pass — not Drawbore, not Tenon, not Spline, not Kerf, not Dowel, not a paste well

## Workflow

1. Load the seed: 12 mm of leftover fox — already showing, not a loose-only tenon
2. Read the scene: one stub tenon, a leftover whose leftover is the fox, leftover labelled as a sketch
3. Move leftover fox (or use the arrow keys on the focused slider); leftover names showing or loose
4. Drop the leftover toward 0 mm and the tenon looks loose / no leftover fox; raise it and a larger leftover wedge still sits in the tenon
5. Reset restores the seeded leftover showing

## Data model

One stub tenon with leftover fox as leftover hidden wedge that still sits in the tenon:

- `fox` — millimetres of leftover wedge (default 12)

Derived picture:

- leftover labelled as a sketch (loose / showing), not a mill sign-off
- leftover wedge labelled as a sketch
- loose / no leftover fox when wedge ≤ 2 mm (the tenon looks loose, no leftover wedge flaring it)

Nothing is persisted. Refresh restores the seeded scene.

## Architecture

- static HTML/CSS/JS
- no backend required for the prototype
- one SVG scene: one stub tenon in side/end — a leftover whose leftover is the fox; leftover is leftover hidden wedge still sitting in a kerf in the tenon (the leftover wedge still sitting in the tenon so it flares as it seats; not a drawbore offset through two holes, not a tenon tongue by itself, not a spline key, not a kerf-only blade path)
- moving a control redraws the leftover immediately
- `?embed=1` hides catalogue chrome so the hub living well can iframe this page
- no network, no npm, no localStorage
