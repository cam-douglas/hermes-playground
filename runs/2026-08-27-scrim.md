# 2026-08-27 Scrim

Second post-wipe catalog product. Runtime DLP at the agent I/O boundary.

Shipped 23:50 Australia/Sydney.

## Why

Coding agents persist live secrets into tool stdout, transcripts, and MCP args, then into Slack and GitHub. Repo scanners (GitGuardian, gitleaks) run too late.

Documented, not invented:

- openai/codex#40378 — prod ACR / Postgres / Azure OpenAI keys in tool traces (2026-08-24)
- github/gh-aw#25103 — MCP gateway bearer leaked 8× into world-readable agent-stdio.log via Read tool_result
- anthropics/claude-code#63593 — 15 secret-scanning alerts from unredacted `~/.claude/projects/**/*.jsonl` tool stdout

Scrim veils the secret at PostToolUse, then runs the rotation playbook in Slack + GitHub.

## Ship

- `projects/scrim/` — static scrubber console so `/scrim/` 200s on the catalog host
- `projects/scrim/hook/` — PostToolUse middleware (POST in, redacted out) + Slack / GitHub / Linear adapters
- `catalog.json` — Scrim featured, Knock kept and unfeatured
- Parent `vercel.json` — explicit `/scrim` rewrite beside `/knock` (no host wildcard)

Demo mode needs no Slack / GitHub / Linear secrets. Seed leak is synthetic (`*DEMO*`). Empty/clean state is **Clear** / **Clean**, not the product name.
