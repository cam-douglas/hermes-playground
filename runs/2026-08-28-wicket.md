# 2026-08-28 Wicket

Fourteenth post-wipe catalog product. Gatehouse / turnstile for worktree isolation escapes.

Shipped 12:50 Australia/Sydney.

## Why

Isolation is a pin, not a promise. `isolation:"worktree"` / EnterWorktree sets a default cwd and sometimes a session-wide latch, but Edit/Write with an absolute `file_path` still lands in the main checkout, `git reset --hard` runs one directory up with the guard silent, sibling sessions swap cwd, a parent that idles reaps a live child's unchanged worktree, and EnterWorktree mid-batch flips a session-global latch that then refuses even `pwd` for agents already inside their own worktrees.

Wicket scores a probe against the pinned worktree root and either admits the write (**home**) or names the failure class. Path check is component-containment (`is_relative_to` / parents walk), never a string prefix — `/tmp/wt-other` is not inside `/tmp/wt`.

Documented, not invented:

- [anthropics/claude-code#74726](https://github.com/anthropics/claude-code/issues/74726) — isolation:"worktree" does not sandbox absolute file paths; Edit/Write to main checkout succeeds. Open. PRIMARY seed.
- [anthropics/claude-code#81333](https://github.com/anthropics/claude-code/issues/81333) — worktree-isolated subagent ran `git reset --hard` in the main checkout; guard did not fire (data-loss class).
- [anthropics/claude-code#86584](https://github.com/anthropics/claude-code/issues/86584) — sibling cwd races + idle auto-reap of a live child's worktree.
- [anthropics/claude-code#89102](https://github.com/anthropics/claude-code/issues/89102) — EnterWorktree while subagents run flips a session-wide isolation latch; even `pwd` refused for agents in their own worktrees.
- [anthropics/claude-code#85448](https://github.com/anthropics/claude-code/issues/85448) — isolation binds the worktree's base repo to the caller's Bash cwd at dispatch, not the target repo.
- [anthropics/claude-code#59628](https://github.com/anthropics/claude-code/issues/59628) — worktree sessions can edit files in the parent main checkout with no guardrail.
- [anthropics/claude-code#56137](https://github.com/anthropics/claude-code/issues/56137) — isolation:"worktree" does not actually isolate subagent file writes.
- [anthropics/claude-code#64322](https://github.com/anthropics/claude-code/issues/64322) — Edit-tool path validation must be component-containment; string-prefix matching is insufficient (`/tmp/wt-other` vs `/tmp/wt`).

Wicket admits, refuses, rebounds, holds, or clears. Verdicts: home, escape, latch, reap, swap, misbind. Slack isolation alarm, GitHub isolation ledger, Linear data-loss incident on escape that mutated main or reset --hard. Missing secrets stay honest demo rows, never a fake live 200. Idle word is **home**.

This is NOT Hasp (file lease), Stencil (plan bleed), Reveille (muster), Sigil (wax-seal clinic), Suture (stream tear), Blot (image poison), Coda (silent text drop), Reed (MCP registry), Fathom (standing rules after compact), Parity (claim vs reality), Quench (token fuse), Scrim (DLP), or Knock (permission grants). Not a leftover woodworking slider.
