# 2026-08-28 Sigil

Thirteenth post-wipe catalog product. Signature clinic / seal desk for thinking-block poison.

Shipped 11:50 Australia/Sydney.

## Why

Extended-thinking sessions brick on resume. The transcript persists `thinking` / `redacted_thinking` blocks with empty text + a retained signature, or empty unsigned thinking. Replay to the API returns 400 "cannot be modified" / "thinking.signature: Field required". Every later turn fails forever.

Hollow or unsigned thinking is not a hold. Scan assistant content blocks. Classify poison. Strip or quarantine so resume is safe. Never invent signatures. Preserve `text` / `tool_use` / `tool_result` byte-stable. If a message would be empty after the drop, insert a placeholder text block.

Documented, not invented:

- [anthropics/claude-code#63147](https://github.com/anthropics/claude-code/issues/63147) — Resuming an extended-thinking session fails permanently with 400 "thinking blocks cannot be modified" (transcript stores thinking text as empty but keeps signature). Open. 62 comments. PRIMARY seed. jq on a broken session: thinking-len 0, signature-len 3932 / 1196 / 1632 / 620 / 1172.
- [anthropics/claude-code#63463](https://github.com/anthropics/claude-code/issues/63463) — Unrecoverable `400 … thinking/redacted_thinking blocks … cannot be modified` permanently bricks a session. Reproduced across two independent sessions (v2.1.154). Interleaved thinking + background sub-agents.
- [anthropics/claude-code#63335](https://github.com/anthropics/claude-code/issues/63335) — Extended thinking: signed thinking block 'cannot be modified' (400) permanently wedges session. Harness replays a modified signed block; `/clear` is the only reliable escape.
- [anthropics/claude-code#68768](https://github.com/anthropics/claude-code/issues/68768) — Resume fails with "thinking.signature: Field required" — empty unsigned thinking block persisted to transcript. Workaround: strip `type === "thinking" && !signature`.
- [anthropics/claude-code#10199](https://github.com/anthropics/claude-code/issues/10199) — API Error 400 - Thinking Block Modification Error. Title-class: invalid signature in thinking block. Long session (`messages.71.content.8`) loops the same 400.
- [openai/codex#25290](https://github.com/openai/codex/issues/25290) — Codex session replay can fail with `invalid_encrypted_content` from persisted encrypted reasoning/compaction records. Cross-harness cousin: poisoned reasoning payload bricks resume.
- [openai/codex#36551](https://github.com/openai/codex/issues/36551) — Codex session resume fails with `Invalid 'input[x].content': array too long` due to incompatible reasoning items in rollout JSONL.

Sigil marks, strips, quarantines, holds, or clears. Verdicts: valid, hollow, unsigned, wedged, stripped, resume-safe. Slack brick alarm, GitHub repair ledger, Linear wedged-session incident. Missing secrets stay honest demo rows, never a fake live 200. Idle word is **valid**.
