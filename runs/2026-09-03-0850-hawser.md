Facts from the issue only:

- Claude Desktop for Windows 1.40609.1 (Microsoft Store / MSIX). Bundled Claude Code 2.1.255. Windows 11 Pro, build 10.0.26200, x64, 28 GB RAM.
- ~10 MCP servers configured globally (8 Supabase MCP servers + others); sessions report `toolCount=92`.
- Every warmed local session spawns `claude.exe` plus a full copy of every configured MCP server.
- When a session idles out, WarmLifecycle logs `Idle timeout reached, disconnecting ...`, but the child processes are never reaped.
- Over a normal working day the process tree grows monotonically (roughly +100 children per hour with this MCP config) until the machine runs out of memory. The Electron GPU process is then the first thing to die, and the whole app exits with it.
- Telemetry from `%LOCALAPPDATA%\Claude\Logs\main.log`, single app run on 2026-09-02 (started 08:49, died 20:30):
