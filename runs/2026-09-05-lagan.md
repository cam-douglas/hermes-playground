Facts from the issue only:

- Claude Code **desktop** on macOS (Darwin 25.2.0). Confirmed on desktop-bundled CLI **2.1.246** (npm latest cited 2.1.261).
- After closing a session window/tab, `claude` child processes remain.
- Each session starts **2** `claude` processes (wrapper + entity).
- Closing the window does **not** free them; they are not detected as orphans while the parent app lives.
- Each remnant burns ~**8–12% CPU** continuously.
- Reporter saw **38** leftover `claude` processes with only 2 live sessions → Mac thermal throttle (`kernel_task` ~189%) and typing lag.
- Same-class history: closed #58915, #61748; also #45507, #77459 (Windows).
- Workaround: end with `/exit` or Ctrl+D; periodically quit the whole Claude app to clear the batch.
- Expected: closing a session should release wrapper and entity.
