## Problem

A second casing is not a plot. On Windows, `~/.claude.json` holds two project keys that differ only in case for the same directory. PowerShell refuses the file on `DuplicateKeysInJsonString`. `claude mcp add -s local` keys by the launching shell's cwd string, so a server registered under `Project1` is invisible to a session reading `project1`. Five keys for two real directories. Identity is the problem: one physical directory, many case/slash spellings used as case-sensitive JSON keys.

## Why Iota

An iota is the smallest letter. On a typesetter's case, upper and lower drawers hold one sort. A second casing is not a second plot. Score the keys. Name the class or admit **bound**. Idle word is **bound** (one sort, one drawer; no second casing). When `.claude` and `.Claude` both sit in the file: **split**.

Verdicts: bound, split, twinned, hidden, unparseable, dropped, mixed, open, aliased, true.
