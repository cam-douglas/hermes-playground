## Problem

A first delivery is not a hold. When a subagent (depth 1) spawns its own child (depth 2), the child's first answer is delivered to the parent. If the parent then uses SendMessage to ask the same child a follow-up, the child answers, but the answer is delivered to the root session. The parent receives nothing and parks. The child sees `from="general-purpose"` — an agent type, not an address — and an explicit reply fails with `No agent named 'general-purpose' is reachable`. Hypothesis from the issue (not a claim): recipient helper resolves the parent only while the parent is running, or completed and still holds keepalive `agent:<taskId>`; that keepalive is cleared after the first notification, so a parked parent falls back to root.

## Why Shunt

A shunt is a railway movement that puts a wagon on a road. When the points throw the wrong way, the follow-up leaves the parent road and arrives at root. Score the road. Name the class or admit **stabled**. Idle word is **stabled** (wagons in the right road; no misroute). When the first answer went to the parent and the follow-up queued to root: **misrouted**.

Verdicts: stabled, misrouted, orphaned, rootbound, typecast, stalled, tandem, dropped, crosstalk, sidetracked.
