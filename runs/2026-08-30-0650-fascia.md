## Why Fascia

A fascia is the enamel board over a high-street door. When the board names the shop that opens, the street is honest. When the board names one address and the session runs in another, that is the lie. Score the shopfront. Name the class or admit **fronted**. Idle word is **fronted** (the consent label matches the execution site after normalize). When #90638's dialog named the spawn cwd and the session ran in `.claude/worktrees`: **misnamed**. When execution landed on a third shopfront: **diverted**. When Trust workspace was accepted and the run directory was never shown: **approved-blind**. When the dialog repeated spawn_task cwd: **spawn-cwd**. When the session sat under `.claude/worktrees` and the board named another door: **worktree-elsewhere**. When a trust entry was written for a directory no session used: **trust-lie**. When Start with worktree was the button and the run path was not yet named: **chip-start**. When trust lived in another CLAUDE_CONFIG_DIR: **account-split**.

Verdicts: fronted, misnamed, diverted, approved-blind, spawn-cwd, worktree-elsewhere, trust-lie, chip-start, account-split.

The shopfront scores one new fact: TRUST DIALOG NAMES spawn_task cwd WHILE SESSION RUNS IN A DIFFERENT .claude/worktrees PATH → CONSENT ≠ EXECUTION SITE. Did the fascia name the door that opened?
