## Thesis

**Entresol** — a gallery mezzanine / intermediate-floor booth for Claude Code #93010: a session started inside a git worktree should load the CLAUDE.md in the directory directly above it when that directory holds the worktree's own repository (docs say every ancestor is read). Instead that parent CLAUDE.md is skipped — every CLAUDE.md above that point loads, and the same parent hands its CLAUDE.md down without trouble to a plain (non-worktree) child. The skip is the specific pairing: child is a worktree OF the repository the parent directory holds. Neither parent/CLAUDE.md nor parent/.claude/CLAUDE.md arrives. Workaround (@-import per worktree) drifts across branches.
