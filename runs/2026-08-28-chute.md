## Problem

Claude Code has no sanctioned channel to hand it a secret. The only surface is the chat prompt, which IS the transcript: three on-disk stores, re-sent every turn, five-year retention via /bug. That single gap maps to 18+ open issues with zero shipped. Pasting a PAT is the failure mode. Reading `.env` into the transcript is the failure mode. The model printing the value is the failure mode.

## Why Chute

Chute is a brass mail chute in a night lobby. Drop the secret through the door. The value never enters the transcript or the model context. It lives in process/session memory only, shows a fingerprint, and lets the agent USE the secret via env inject while never READING it. A typed secret is not a handoff. Name the class or admit **clear**.

Idle word is **clear** (chute empty; no secret on the transcript path). Verdicts: clear, typed, masked, burned, echoed, retained, brokered, vaulted, leaked, gap.
