## Problem

An empty plate is not a keyhole. The sandbox seats a fresh empty tmpfs over `/run/user`. The env still names the bus. `gh` blames the token. `allowUnixSockets` is inert on Linux. `excludedCommands` is inert. `dangerouslyDisableSandbox` still masks. The only escape is plaintext `hosts.yml`, and denying Read on that file then breaks `gh` itself.

## Why Escutcheon

An escutcheon is the locksmith's keyhole plate — the furniture around the hole. The plate is still on the door. The hole has no socket behind it. Score the door. Name the class or admit **plated**. Idle word is **plated** (honest control: real runtime dir bound, D-Bus socket present, keyring reachable). When #90717's empty tmpfs + lying address + token-blame: **blamed**. When only the mount mask shows: **masked**. When the env address lies: **lying-address**. When `allowUnixSockets` is named and inert: **sockets-inert**. When `excludedCommands` is named and inert: **excluded-inert**. When `dangerouslyDisableSandbox` still masks: **still-masks**. When plaintext is the only escape: **plaintext-forced**.
