## Problem

The pulpit spoke; the nave never heard. PermissionRequest delivers a systemMessage that Claude Code accepts, validates, and logs as success. The ExitPlanMode "Ready to code?" approval card never shows it — TUI and VS Code both stay blank. Hook plumbing is intact (side effects, OSC/BEL). Only the display path at this prompt is missing.

Name the class or admit **unheard**. Idle word is **unheard** (honest control: systemMessage actually rendered on the approval card).
