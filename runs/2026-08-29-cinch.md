## Problem

A written Trusted-folders list is not a hold. Scheduled / unattended Cowork tasks intermittently fail to mount folders that are already connected and reliable in interactive sessions. A different subset drops every run. Adding folders to Trusted Cowork folders does not stop it. The worst case treated a surviving leaf path as proceed and delivered a VP-level report with two entire sections silently omitted — no error, no placeholder, presented as complete.

## Why Cinch

A cinch is the strap that holds a pack on a saddle. Score the tack room. Name the class or admit **cinched**. Idle word is **cinched** (every expected folder is mounted and reachable). When one trusted folder is missing this run: **slipped**. When two or more expected folders are missing: **dropped**. When a surviving leaf was treated as proceed: **omitted**.

Verdicts: cinched, slipped, dropped, phantom, omitted, partial, trusted, loose, delivered, halted.

The desk scores one new fact: an unstable mount set on an otherwise-fired run. Leaf-proceed plus a missing root is omitted / delivered, not cinched, even when some paths exist.
