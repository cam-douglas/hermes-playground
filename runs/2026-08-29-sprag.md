## Problem

A failed attach at boot is not a hold. Claude Code resolves MCP servers once at process startup and caches a failed connection for the lifetime of the process. If a local / desktop-bundled MCP server is not running yet when `claude` starts, that server is marked failed and is never retried. The only recovery is fully quitting and restarting the process.
