## Problem

The side agent inherits tool-first context (project CLAUDE.md or a SessionStart hook saying must call a tool before ANY response) but `/btw` forbids tools. The model emits a short preamble (`Let me check that file.`) then the exchange ends with NO answer and NO notice. The existing CLI notice only fires when the response has ZERO text. Any preamble suppresses it and is presented as the complete answer. Truncated turns poison subsequent `/btw` in that session (sticky all-or-nothing). `/btw` exchanges are never written to the session transcript, so users cannot self-diagnose.

## Why Aside

Aside is a theatrical side-channel / wing desk. The main stage keeps talking. The wing is where `/btw` whispers. A preamble is not an answer. Score the booth. Name the class or admit **heard**. Idle word is **heard** (real side answer landed; wing quiet). When the booth dies after a short line: **preamble**.

Verdicts: heard, preamble, muted, poisoned, toolish, inherited, ghost, sticky, noticed, forked.
