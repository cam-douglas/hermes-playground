Truncation always mid-PATH, no closing quote, no trailing newline. Each plugin contributes ~105 chars (`.../AppData/Roaming/Claude/local-agent-mode-sessions//plugin_/bin`). On-disk repair does not recover the running session — content is captured in memory. Deleting the snapshot makes commands silently no-op (exit 0, no output). ## Problem

A written shell snapshot is not a hold. The snapshot writer clips PATH at the Windows cmdline wall. The quote never closes. Every Bash call dies. Repairing the file does not heal the session. Deleting it mutes Bash. Plugins are the length, not a viable off-switch.
