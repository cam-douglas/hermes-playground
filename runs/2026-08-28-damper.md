## Problem

Remote Control opens a remote bridge. Tool results and file contents can cross it. Docs list only explicit activation paths. In the wild, new sessions start with RC already on. A settings toggle that reads off is not a hold. The flue opens before you throw anything.

## Why Damper

A chimney damper is a plate in the flue. Closed, the fire is banked and there is no draft. Open, the chimney draws. If the plate swings open by itself, smoke and heat leave the house without anyone touching the handle. That is Remote Control auto-enable. Score the flue. Name the class or admit **banked**. Idle word is **banked** (fire banked, damper closed, no remote draft). When a new session starts already drawing: **defaulted**.

Verdicts: banked, drawn, vented, ajar, forced, defaulted, bridged, disclosed, sealed, lit.
