Facts from the issue only:

- `.git/index` belongs to the repository, not to the session. A commit's tree is built entirely from the index, never from a diff against HEAD.
- Lightweight workaround for multi-session collisions: each session sets `GIT_INDEX_FILE` to a private index. That trades a visible collision for silent data loss.
- Stale private index relative to the new HEAD: lacks a path the other session added → commit DELETES it; holds the pre-commit blob for a path the other session changed → commit REVERTS it to the old content.
- Revert is dangerous: the file stays present and plausible while the work inside is gone. `git show` lists the collateral files but the title looks like "add b.txt". Victim `git status` shows ordinary modified + untracked — indistinguishable from agent noise.
- A worktree is immune, because it has its own HEAD as well as its own index, so nothing can lag.
- No error messages: the operation succeeds, exits 0, and prints nothing.
- Damage from the reproduction, where session B touched only `b.txt`: D a.txt, A b.txt, M shared.txt (shared.txt now = v1; A had set it to v2).
- Repro: one repo, one branch, two concurrent sessions. B seeds a private index and stages one file. A stages different paths and commits. B commits → A's added file arrives as a deletion, A's modified file is reverted.
- Section 5: B's commit leaves the shared index staging the deletion of a file that exists on disk and was committed seconds earlier.
- Section 6: genuine deletion does not trip the proposed guard.
- Proposed guard: refuse to commit on a staged deletion whose file still exists on disk.
- Real-world: 11+ interactive sessions plus scheduled automation in one tree; five separate incidents.

## Problem

STALE PRIVATE `GIT_INDEX_FILE` ON A SHARED HEAD. A commit titled "add b.txt" deletes the other's adds and reverts the other's blobs. Exit 0. No conflict. No prompt.

## Why Spoil

A spoil tip is the waste bank beside a mine. If the assay tray is stale relative to the last bank, the next dump can bury living ore and put last week's slag back on the seam. Two sessions on one working tree are those wagons. Idle **banked** is an index that matches HEAD (commit would not delete living paths). Seeded **spoiled** is the #90943 stale-private-index commit. A spoiled index is not a hold. Score the spoil or admit **banked**.
