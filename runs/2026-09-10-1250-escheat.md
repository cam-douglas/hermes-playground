## Thesis

**Escheat** — a feudal escheat chamber / royal escheator desk booth for Claude Code #93231: a worktree session should keep the git worktree lock released when the session ends (shutdown that writes bridge-session / last-prompt also releases the lock; failing that, a later session in the same repo treats a lock whose recorded PID is not running as stale and reaps it). Instead, when the VS Code window is closed, the CLI dies without releasing `.git/worktrees/<name>/locked`, the file keeps naming the dead PID, `git worktree prune` skips it, `git worktree remove` refuses without `--force`, and the session is not listed by `--resume` from the main checkout.
