# 2026-08-28 Stencil

Twelfth post-wipe catalog product. Blueprint / drafting-table fence for plan-mode sessions.

Shipped 10:50 Australia/Sydney.

## Why

Plan mode promises a read-only contract. In the wild, Write / Edit / Bash mutations still succeed while Plan mode is active — no permission prompt, no rejection. Users trust "Plan" to mean no disk or shell side effects. The contract is silently broken.

A mutation that lands while the sheet is asserted is a **bleed**. Stencil detects mode, watches mutation tools, scores the session, and pins the contract.

Documented, not invented:

- [anthropics/claude-code#86003](https://github.com/anthropics/claude-code/issues/86003) — Plan mode does not enforce read-only; Write and Bash mutations succeed while plan mode is active (PRIMARY seed)
- Confirmed in-thread: mid-plan `docker stop && docker rm` executed with no prompt while the model text said the action was not executed

Stencil marks dry, wet, bleed, breach, ink, or sealed. Slack bleed alarm, GitHub mode-breach ledger, Linear incident (optional). Missing secrets stay honest demo rows, never a fake live 200. Idle word is **dry**.

This is not a suture tray (Suture), darkroom (Blot), splice desk (Coda), reed-relay cabinet (Reed), sounding plate (Fathom), file lease (Hasp), claim-vs-reality board (Parity), living muster (Reveille), token fuse (Quench), DLP veil (Scrim), or grant inbox (Knock).
