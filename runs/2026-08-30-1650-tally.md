## Problem

A birth-counted tally is not a hold. The dialog notches age since worktree birth. Risk against `origin/main` is already zero. The slate still says the cargo will be lost.

## Why Tally

A dock tally is a chalk-stick count of crates on the quay. The `/exit` dialog chalks commits since the worktree was born — `CLAUDE_BASE` — and then treats that number as cargo that would be dumped. Score the board. Name the class or admit **squared**. Idle word is **squared** (accounts squared / dock tally squared; hold is quiet). When #90692's birth count is N>0 while `origin/main..HEAD` is 0 and the dialog claims loss: **false-loss**. When the baseline is worktree birth: **birth-counted**. When a regular/ff merge still leaves N>0: **merged-still-n**. When commits are already on the remote: **push-blind**. When `CLAUDE_BASE` is frozen at creation: **base-frozen**. When `git merge --ff-only origin/main` grows N while risk shrinks: **remount-grew**. When origin count is 0: **origin-zero**. When the slate is notched age, not risk: **chalked**. When the nearby bug is #84856 squash-ancestry ExitWorktree *tool*: **keep-or-lose**.

Verdicts: squared, birth-counted, false-loss, merged-still-n, push-blind, base-frozen, remount-grew, origin-zero, chalked, keep-or-lose.
