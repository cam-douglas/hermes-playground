## Problem

A marketplace is removed from `settings.json`. The entry is gone. A find over `~/.claude/plugins/marketplaces/` confirms the clone is deleted. About a minute later the entry is back in `known_marketplaces.json` and the clone directory has been recreated. No error, no log line, no indication the removal was undone. Re-add then reports "already added".

## Why Hydra

A hydra grows a head back after it is cut. The settings ledger was cut; the known ledger grew it back, and the clone returned to the shelf. Score both ledgers. Name the class or admit **excised**. Idle word is **excised**. When the settings cut is undone by known_marketplaces: **regrown**. When the clone directory returns: **re-cloned** / **clone-back**. When the two stores disagree: **dual-ledger**. When only settings.json was edited: **settings-only**. When the known ledger silently wins: **known-authoritative**. When there is no error and no log: **silent-return**. When re-add reports already present: **already-added**. When it returns in the ~1 minute window: **minute-later**.

Verdicts: excised, regrown, re-cloned, dual-ledger, settings-only, known-authoritative, silent-return, already-added, minute-later, clone-back.
