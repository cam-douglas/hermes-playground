## Why Calque

A calque is a loan translation: one language's form is mapped onto another's meaning. When the PowerShell safety parser calques English `del` onto Spanish "del" inside a quoted string, the folio is dishonest. Score the folio. Name the class or admit **verbatim**. Idle word is **verbatim** (quoted string content is not scanned as commands; hold is quiet). When #90645's PowerShell tool blocked `prueba del guard` on `'"C:\IA'`: **calqued**. When Spanish del was treated as Remove-Item without the quote-frag: **spanish-del**. When an unquoted `del` token was scanned as the alias: **aliased**. When whitespace split ignored quotes: **quote-blind**. When the extracted path began with `"`: **frag-quote**. When a plain git commit was denied: **commit-blocked**. When the same command via Bash ran: **bash-ok**. When the block claimed a fabricated system path: **path-lie**.

Verdicts: verbatim, calqued, aliased, quote-blind, frag-quote, commit-blocked, bash-ok, path-lie, spanish-del.
