## Problem

A written plugin command is not a hold. In Claude Code 2.1.251, every plugin-provided slash command fails to resolve in headless `-p` mode. The wrapper that only checks exit code / `is_error` records success and stores `Unknown command: /<plugin>:<cmd>` as the analysis. Two things would each have contained it: resolving the command, or returning a non-zero exit / `is_error: true` when a command cannot be resolved.
