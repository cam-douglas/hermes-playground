# 2026-08-19 — Ghost Briefs

## Date

2026-08-19

## Thesis

After agents flood a team with code, the missing product is not another harness or handoff console — it is a local, human-only map of which shipped subsystems still have a named person who can brief them, and which are ghosts.

## Inspiration

- Faros *Acceleration Whiplash* (finished work up, incidents/PR and review time and churn up much faster)
- Storey’s Triple Debt: technical / cognitive / intent
- Crowded Aug 2026 GitHub week of harnesses, skill packs, routers, and memory
- Distinct from Reorder Radar (inventory) and from the retired Aug 11–17 pressure/handoff console

Decision expiry was considered and discarded the same day: a weaker wedge than post-merge human fluency.

## What shipped

- `products/ghost-briefs/` static prototype: dossier board, fluency votes, 90-second briefs, ghost/orphan/debt strip, demo-week fixture, reset, localStorage, JSON export/import
- Catalogue hub rewritten as a multi-product index; Ghost Briefs featured, Reorder Radar kept first-class
- Root README updated for both live routes
- This run log

## Verification

- Catalogue `/` lists both products and links to `/products/ghost-briefs/` and `/products/reorder-radar/`
- Product loads with nine seeded subsystems and no orphans until demo week
- Demo week applies the fixture vote set; Feature flags and Schema migrations appear on the red Orphan list
- Filing a named three-sentence brief on an orphan drops ghost count and fluency-debt, and stamps the card `briefed by <name>`
- Refresh keeps votes and briefs
- Export JSON / import JSON round-trips signer, votes, and briefs
- Reset restores the seed
- Reorder Radar page still loads and is unchanged except for catalogue context

## What broke / caveats

- Fluency is a single local vote per subsystem, not a multi-person tally
- Owners on seed cards are labels only; briefing does not reassign the seed owner field
- No backend, so "the team" is whoever shares this browser (or an exported JSON file)
- Demo week clears briefs only on the two fixture orphans so the rail can appear immediately
