# 2026-08-28 Reed

Eighth post-wipe catalog product. Reed-relay cabinet for MCP / tool-registry death.

Shipped 05:50 Australia/Sydney.

## Why

After a transient MCP disconnect the session keeps talking. `/mcp` may say connected. One retry may succeed. Then tools are gone for the rest of the session: `No such tool available`. The respawned process can leak. Codex has the same class.

Connected is not registered. One served call is not a hold. Reed keeps four independent contacts on every MCP server: **alive**, **handshake**, **listed**, **callable**.

Reed probes, kills, respawns, reseats, or drops remotes. Verdicts: open, set, stuck, chatter, leak, drop. Slack registry alarm, GitHub reed ledger, Linear reseat ticket. Missing secrets stay honest demo rows, never a fake live 200. Idle word is **open**.

This is not a sounding plate (Fathom), file lease (Hasp), claim-vs-reality board (Parity), living muster (Reveille), token fuse (Quench), DLP veil (Scrim), or grant inbox (Knock).
