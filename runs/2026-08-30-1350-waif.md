## Problem

An abandoned child is not a hold. The model already saw the timeout. The find/grep tree was never killed.

## Why Waif

A parish foundling home takes in a child left at the gate. When Bash times out and walks away, the children are left on the step. Score the ward. Name the class or admit **sheltered**. Idle word is **sheltered** (child taken in / tree reaped; hold is quiet). When #90672's orphans keep running after timeout: **abandoned**. When Windows never used `taskkill /T`: **taskkill-skipped**. When no Job Object: **job-missing**. When POSIX did not kill the process group: **group-unkilled**. When the tracked shell is gone: **parent-dead**. When descendants still run: **tree-alive**. When CPU/AV load is the tell: **defender-load**. When the model already has the timeout error: **timeout-seen**. When children outlive a dead parent without the full triad: **orphaned**. Gaff false-complete is **off-ward**.

Verdicts: sheltered, abandoned, orphaned, tree-alive, parent-dead, timeout-seen, group-unkilled, job-missing, taskkill-skipped, defender-load, off-ward.

The ward scores one new fact: BASH TIMEOUT RETURNS AN ERROR TO THE MODEL BUT DOES NOT KILL THE CHILD PROCESS TREE. Was the child taken in?
