# 2026-08-28 Blot

Tenth post-wipe catalog product. Darkroom tray for image-poisoned sessions.

Shipped 08:50 Australia/Sydney.

## Why

A bad image block is not a hold. One unreadable frame bakes into the session JSONL. Every later turn 400s. The session is dead. Users abandon hours of context. Extension-as-image (HTML 404 saved as `.png`), HEIC, Git LFS pointers, error text in a `.png`, valid-magic / corrupt-pixel PNGs, and Codex HEIC threads all produce the same class: the rejected payload is replayed forever.

Blot inspects every image frame, scores it, and strips the blot. The poison block becomes a text placeholder so the session can continue.

Documented, not invented:

- [anthropics/claude-code#24387](https://github.com/anthropics/claude-code/issues/24387) — corrupted / mismatched image permanently breaks session; 400 loop; 173-byte OSStatus error written to screenshot.png; strip-images workaround (PRIMARY seed)
- [anthropics/claude-code#16169](https://github.com/anthropics/claude-code/issues/16169) — HEIC permanently destroys the session
- [anthropics/claude-code#32764](https://github.com/anthropics/claude-code/issues/32764) — Git LFS pointer file Read as icon.png → unrecoverable loop
- [anthropics/claude-code#47391](https://github.com/anthropics/claude-code/issues/47391) and [#50708](https://github.com/anthropics/claude-code/issues/50708) — tool-returned / Read PNG baked in; later 400; compact also dies
- [openai/codex#10833](https://github.com/openai/codex/issues/10833) and [#7214](https://github.com/openai/codex/issues/7214) — HEIC upload; thread stuck on "Invalid image in your last message" / reconnect loop

Blot marks, strips, abandons, or clears. Verdicts: clear, heic, lfs, spoof, rot, replay. Slack blot alarm, GitHub blot ledger, Linear recovery ticket. Missing secrets stay honest demo rows, never a fake live 200. Idle word is **clear**.

This is not a splice desk (Coda), reed-relay cabinet (Reed), sounding plate (Fathom), file lease (Hasp), claim-vs-reality board (Parity), living muster (Reveille), token fuse (Quench), DLP veil (Scrim), or grant inbox (Knock).
