## Why

A standing CLAUDE.md is not a hold. An ack is not a hold. For Opus 5 only, a server-gated section (`tengu_heron_brook`, gated on `opus_5_prompt_bundle`) is concatenated into the system prompt with no author label. It says "Do not call the AgentTool unless the user requested it" and "Do not use workflows or deep-research unless the user requested it." There is no settings key, no `CLAUDE_CODE_*` env, and `CLAUDE_INTERNAL_FC_OVERRIDES` is dead code. The injected line outranks the user's own rule. The model often attributes the edict to the user. Session transcripts do not record the system prompt.

This is NOT Fathom. Fathom is eviction: compaction drops standing rules from the window. Veto is injection: a vendor overlay sits on top of a rule that is still in the window. Different failure, different UI, different backend, different idle word (**upheld**, never Fathom's **still**, never Assay's **sterling**).
