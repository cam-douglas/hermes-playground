## Why Tumbler

A tumbler is a pin stack that should **honor** a PermissionRequest key so `ExitPlanMode` allow retracts the bolt. Instead the tumblers accept the key (hook fires, stdin delivered, stdout allow read) then silently discard the decision so the plan-approval chooser still blocks. Idle **honored** is allow applied; chooser skipped; updatedPermissions take effect; plan implements. Seeded **discarded** is the #74256 allow discard. Score the keyway or admit **discarded**.
