## Problem

Forking from the Claude Code VS Code extension while Remote Control is enabled produces a new window with the healthy banner `Remote Control is active · Continue here, on your phone, or at claude.ai/code` and **zero inherited conversation history**. The child is not recorded as a fork. Transcript opens as `bridge-session` with `lastSequenceNum: 0`. Desktop session record `kind: interactive` with NO `forkedFromSessionId`. First user record `parentUuid: null`. Silent (no error). Parent quiesced 2s before child `startedAt`. Same parent forked successfully when the result was NOT bridged (identical 9,363,037 bytes / 3942 records, UUID-swap fingerprint).

## Why Scion

A scion is a cutting taken from a parent tree and taped onto rootstock. The graft is only a hold if the cambium lines up and the annual rings continue. #90815 taped a healthy-looking scion with RC sap still flowing — and no rings. Score the cambium. Name the class or admit **hollow**. Idle word is **hollow**. When lastSequenceNum is 0, forkedFrom is missing, and the banner is healthy: **empty-fork**. When the bridge path wins: **bridge-won**. When there is no parent pointer: **unlineaged**. When sequence is zero: **lastSequenceNum-0**. When the fork key is absent: **no-forkedFrom**. When there is no error: **silent-drop**. When the entrypoint is the VS Code extension: **vscode-rc**. When the parent quiesced 2s before start: **race**. When the banner looks fine: **healthy-banner**. When the child has no inherited records: **seedless**.

Verdicts: hollow, lined, taken.
