## Why

A parsed call is not a hold. The harness often treats a successfully-parsed tool call as a hold, but the open issues themselves show several distinct impurities: a parse that succeeds while a string is silently corrupted with an adjacent parameter's boundary tag; a tag-grammar parser that absorbs later blocks on a mangled close (6.2% silent field loss); Opus 4.8 unparseable calls whose retry also failed; Opus 4.7 leaking legacy XML tool-use into JSON; `court` / `call` + invoke rendered as plain text so Bash/Edit never run while the UI looks like progress; a malformed leftover that contaminates later history; Codex truncated or string-typed arguments; and malformed search arguments that poison resume.

Assay is a cupellation house. Ore samples sit on a crucible rail. A purity spectrogram names the class. Heat the envelope. Weigh delivered arguments against the declared schema and the raw markup. Name the impurity or admit **sterling**. Fail-closed on tainted / absorbed / garbled.
