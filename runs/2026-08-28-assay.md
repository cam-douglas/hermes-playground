## Why

A parsed call is not a hold. The harness often treats a successfully-parsed tool call as a hold, but the open issues themselves show several distinct impurities: a parse that succeeds while a string is silently corrupted with an adjacent parameter's boundary tag; a tag-grammar parser that absorbs later blocks on a mangled close; Opus 4.8 unparseable calls whose retry also failed; Opus 4.7 mixing legacy XML tool-use into JSON; a stray `court` token and a dropped `antml:` namespace; unicode-escaped arguments that fail JSON parse; a malformed leftover that contaminates later history; Codex truncated `function_call.arguments`; and Codex `tool_search_call.arguments` sent as a JSON string.
