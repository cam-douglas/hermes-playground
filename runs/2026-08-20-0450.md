## What shipped

- Root `index.html` shareable desk: persist search in `q` and active tag in `tag` (`/?q=unicode`, `/?tag=inventory`, `/?q=skill&tag=review`)
- On load, query params apply to the search field, the active tag, and the visible cards
- Typing or clicking a tag uses `history.replaceState` (no extra history entries)
- Clearing search/tags strips the params back to `/`
- Visible **Copy desk link** copies the current filtered URL
- Still Inside stays featured this hour; the other eight stay first-class under Archive
- Search + tag still AND; empty state still names the query; match counts still update
- Snapshot stays 9 products, 0 backend, 1 this hour / 8 archive
- All existing product URLs unchanged; no `products/<new-slug>/`
- Root README and this hourly run log
