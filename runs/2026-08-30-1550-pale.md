## Problem

A session beyond the pale is not a hold. The settings file is on disk under the repo. The loader never walked up. Every project hook is silently absent.

## Why Pale

An English pale is a fenced jurisdiction. Hooks bind only *inside* the pale — the resolved project root. Start from a parent, a package subdirectory, or any miss of that root, and the fence is not walked. Score the fence. Name the class or admit **bound**. Idle word is **bound** (within the pale / hooks bound; hold is quiet). When #90683's parent-of-repo start leaves hooks absent with no warning: **beyond**. When settings sit on disk and zero hooks are armed: **unhooked**. When project-root resolution missed the settings dir: **rootless**. When nothing warned: **silent**. When started in a parent: **above**. When launched from a package subdirectory: **subdir**. When the loader never walked up: **walkless**. When a write proceeded without the blocking hook: **fail-open**. Chatelaine/Waif/Berth-shaped different bugs are **off-pale**.

Verdicts: bound, beyond, unhooked, rootless, silent, above, subdir, walkless, fail-open, off-pale.
