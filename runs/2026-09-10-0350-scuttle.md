## Thesis

**Scuttle** — a naval damage-control / shipyard booth for Claude Code #93154: on a transient SSH blip, remote-session warm-up should REATTACH to a still-healthy remote daemon. Instead warm-up failure (`channel_closed_no_socket` → `bridge_startup_timeout`) issues `server.shutdown` via `RemoteServerController` / `server --stop` WITHOUT probing whether the daemon is still alive, and the daemon SIGKILLs every tracked child session (blast radius: 10 live `ccd-cli` sessions / 42 process groups in the report). The same binary already has a non-destructive daemon-takeover path (SIGTERM-first; children orphaned and surviving); only the RPC shutdown path is unconditionally destructive. Score scuttled or admit moored.
