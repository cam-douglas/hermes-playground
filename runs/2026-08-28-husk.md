## Problem

A husk is not a hold. Headless Claude Code (and Agent SDK / Actions) can report success when the model never ran. Exit 0, `subtype:"success"`, `is_error:false`, empty `result`, `num_turns:0`. Orchestrators that key off exit code or the typed success subtype swallow a no-op.

## Why Husk

Husk is a threshing desk. Paste or pipe the result envelope. Score it. Name the class or admit **kernel**. Idle word is **kernel** (a real turn ran — seed present). When hollow: **husked**. More specific classes name the trigger: aborted (failing preamble), denied (untyped stderr while typed denials are empty), nested / contended (parent-session / single-flight lock), zeroed / ghosted (variants of hollow success).

Treat husked as failure even when Claude exited 0.

## Why not a clone

Different failure (pre-turn abort with a success-shaped envelope), different UI (threshing floor / grain mill — warm straw, chaff, barn timber, millstone, amber wheat, dusk barn light), different backend (envelope scorer, not a permission inbox, palimpsest, furnace, or gatehouse), different idle word (**kernel**).
