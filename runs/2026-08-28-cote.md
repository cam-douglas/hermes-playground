## Problem

Claude Code `--resume` registers the agent-team hub under a throwaway startup placeholder session id. Placeholder id `PPPPPPPP-…` is minted at process start. The team hub is created as `~/.claude/teams/session-PPPPPPPP/` with `leadSessionId` = `PPPPPPPP` one second after launch, before resume finishes. No transcript `PPPPPPPP*.jsonl` exists. The live transcript is `RRRRRRRR-….jsonl`. Spawned agents get `--parent-session-id RRRRRRRR` but `--team-name session-PPPPPPPP`. `SendMessage(to: team-lead)` returns `{success:true, message:"Message sent to team-lead's inbox", msg_id}`. The inbox file is emptied to `[]` while the parent is mid-turn. That `msg_id` appears ZERO times in the parent transcript. Named agents park idle forever. A fresh session on the same machine/version round-trips in 1.3 s because its `leadSessionId` matches its real transcript. Team creation snapshots `sessionId()` before `--resume` replaces the placeholder. Nothing re-stamps `leadSessionId`. A success receipt is not a roost.

## Why Cote

Cote is a dove-cote / pigeon loft. Numbered nest holes. Leg bands (session ids). A trap / hopper that can take a bird (inbox → `[]`) without handing it to the keeper. Loft clock. Slate board for the score. A success receipt is not a roost. Score the loft. Name the class or admit **roosted**. Idle word is **roosted** (the bird is in the correct cote; hold is current). When the hopper empties the inbox and the parent never sees the band: **drained**.

Verdicts: roosted, lofted, flown, drained, parked, stray, banded, crossed, consumed, late.
