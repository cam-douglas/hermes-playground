## Problem

A login without a destination is not a hold. MCP 2025-06-18 Authorization requires the RFC 8707 `resource` parameter (MUST) on both `/authorize` and `/token`. On Claude Code 2.1.251 the client sends neither. The issued access token therefore carries `aud=<client_id>` (the client's default audience) instead of the MCP server's canonical resource URI, and spec-compliant (strict) MCP servers reject it with 401.
