# 2026-08-31 Kindling

Seventy-seventh catalog product. Blacksmith / camp hearth / firebox / kindling-rack desk — charcoal, ember orange, ash gray, banked-coal red; Fraunces + DM Sans + JetBrains Mono — for Claude Code Desktop WarmLifecycle throwaway CLI sessions. Every focus switch pre-warms via WarmLifecycle and spawns a fresh Claude Code CLI session that is then never used. When the conversation resumes, the app maps the local session to its pre-existing CLI session. The warm spawn fires SessionStart, writes per-session dirs, increments `claude_code.session.count`, and is discarded without ever receiving a message. Over ~4 weeks one machine: 950 unused sessions vs 57 that hold conversation (94% waste). Disk litter under `~/.claude/session-env/<uuid>/` and `~/.claude/projects/<project>/<uuid>/`. ## Problem

A preview spark that never takes is not a hold. Focus switch → `WarmLifecycle:preview` → `startShellPty` → a fresh CLI uuid that never receives a message. Resume remaps `local_*` to a pre-existing CLI session. SessionStart still fires. session-env and projects dirs stay. `claude_code.session.count` increments. One busy day (2026-08-17): 137 focus switches → 137 startShellPty → 116 on disk → 4 mapped → 113 never used. 91% of on-disk creations align within ±2s of Warming up / startShellPty. Driver is focus-switch count, not message volume.

## Why Kindling

Kindling is the stick you light and throw under a log so the real fire can catch. WarmLifecycle lights a stick on every focus switch and then never uses it — the conversation sits on a different, older log. Score the rack. Name the class or admit **cued**. Idle word is **cued** (honest control: warm reuses/attaches the real CLI session; or warm deferred until attach). When #90798's warm spawn is never mapped: **discarded**. When the preview fires: **warmed**. When SessionStart runs on the throwaway: **session-start**. When dirs stay: **littered**. When session.count increments for unused identities: **inflated**. When resume maps to a pre-existing uuid: **remapped**. When focus switch is the driver: **switch-focus**. When hook stdout lands in discarded tool-results: **hook-ash**. When session.count climbs while tokens/cost/active_time stay flat: **otel-skew**.

Verdicts: cued, warmed, discarded, session-start, littered, inflated, remapped, switch-focus, hook-ash, otel-skew.
