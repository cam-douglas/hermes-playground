## Problem

Claude-in-Chrome pairing is a two-sided channel. The extension claim and the agent session list routinely disagree. The glass live-renders a session the agent lists as `[]`. Two native-host manifests claim the same extension id. Cowork binds actions to a browser on another machine. `isLocal: true` for a remote box. Assigned names collapse to Browser 1/2. A silvered tain is not a hold.

## Why Tain

Tain is the silver backing of a one-way mirror. Face the two panes. Left: what the extension claims. Right: what the agent hears. The tain appears or lifts. Name the class or admit **paired**. Idle word is **paired** (both sides name the same live device; glass is clear both ways). When the glass is one-way: **silvered**.

Verdicts: paired, silvered, ghost, strayed, claimed, nameless, stale, split, dark.
