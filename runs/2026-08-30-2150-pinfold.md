## Problem

A penned spawn is not a hold. The harness composes a long Bypass `-Command`. FileFix matches the CmdLine shape. Spawn never starts. The only in-band line is bare EPERM. Retries are billed. The toast is out of band.

## Why Pinfold

A pinfold is the village livestock pound — the dry-stone fold that holds a stray. The composed `-Command` is the stray goat penned inside. The `.ps1` invoked by path is the ewe grazing free outside. Score the fold. Name the class or admit **penned**. Idle word is **penned** (honest control: short command line, or identical logic as `.ps1` by path; spawn ok; no FileFix). When #90706's FileFix.BBA!MTB matches the CmdLine: **flagged**. When only EPERM is visible: **eperm-bare**. When the long Bypass `-Command` + byte-patch shape is present: **cmdline-shape**. When the threat name is FileFix: **filefix**. When the user saw a toast and the model saw nothing: **toast-only**. When retries fail and are billed: **billed-retry**. When the same logic in a `.ps1` by path runs clean: **script-clears**. When Defender 1116/1117 fire with DidThreatExecute False: **events-1116**. When there is no in-band hint: **undiagnosed**.

Verdicts: penned, flagged, eperm-bare, cmdline-shape, filefix, toast-only, billed-retry, script-clears, events-1116, undiagnosed.
