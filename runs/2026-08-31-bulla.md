## Problem

IN-PLACE MUTATE OF A SEALED MSIX. Updater writes inside the immutable package directory. The CI catalog goes missing. Windows Code Integrity Event 3010 then Event 3033 blocks SwiftShader. The GPU process dies and Electron kills every embedded session. Standalone unpackaged Claude Code stays clear.

## Why Bulla

A papal lead bulla is a sealed lead disc that authenticates a document. The MSIX package catalog is that seal. An updater that writes in place cracks the seal: `CodeIntegrity.cat` is gone, Windows will not load `vk_swiftshader.dll`, the GPU process dies, and the whole Desktop host — with every embedded session — goes with it. A broken seal is not a hold. Score the lead. Name the class or admit **sealed**. Idle word is **sealed**. When the updater writes in place and the catalog is missing: **blown**.
