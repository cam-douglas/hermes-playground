## Problem

A new coat of the same house is not a stranger. The desktop app mints a versioned path. TCC keys the path. The new coat has zero grants. The dialog names a bare version. FDA on the parent house does not cover the child. Cloud mounts each ask again. Morning after an overnight update: a burst.

## Why Livery

A livery is the household uniform of a house — a new coat of the same house is still the house. The versioned `claude-code/<version>/` binary is a new coat. The stable `current` peg is the house peg. Score the wardrobe. Name the class or admit **liveried**. Idle word is **liveried** (honest control: launch from `.../claude-code/current/...`; grants persist; no burst). When #90748's versioned desktop path + zero grants + TCC burst: **prompted**. When every update mints a new path: **path-churn**. When the dialog shows `"2.1.NNN"`: **bare-version**. When old grants remain and the new path has zero rows: **tcc-orphan**. When FDA on `/Applications/Claude.app` does not cover the child: **fda-inert**. When each cloud mount prompts: **cloud-mount**. When the stack arrives first thing after an overnight update: **overnight-burst**. When signing is already stable: **signed-stable**. When the bare version reads as malware: **stranger-path**. When the desktop owns `claude-code/<version>/`: **version-folder**. When launch is from `.../current/...`: **current-shim**.

Verdicts: liveried, prompted, path-churn, bare-version, tcc-orphan, fda-inert, cloud-mount, overnight-burst, signed-stable, stranger-path, version-folder, current-shim.
