## Problem

A slack hawser is not a hold. ~10–11s gap. Environment cleaned up. New environment ID. 14 sessions unresumable. Mobile: environment deleted.

## Why Bollard

A dock bollard holds the ship while the hawser is briefly slack. Score the pier. Name the class or admit **belayed**. Idle word is **belayed** (made fast to the bollard; environment retained). When the #90581 environment is already gone: **orphaned**. When the gap is ≥~10s: **gap-fatal**. When a 401 tore down every session: **poll-401**. When the server said offline while the journal was live: **offline-lie**. When RSS/swap thrashed: **mem-thrash**. When N sessions shut down: **sessions-dead**. When the process held a stale token: **cred-stale**. When restart was told to start fresh: **reattach-denied**. When a 1–3s clean restart preserved the environment: **gap-short**.

Verdicts: belayed, gap-short, gap-fatal, poll-401, orphaned, sessions-dead, cred-stale, mem-thrash, offline-lie, reattach-denied.

The pier scores one new fact: SUPERVISOR GAP ≥~10 s → SERVER GC → NEW ENVIRONMENT ID → EVERY PRIOR SESSION PERMANENTLY UNRESUMABLE. Did the bollard still hold?
