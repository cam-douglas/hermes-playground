## Problem

A missing compaction ticket is not a hold. Context can fall by a material amount between adjacent turns with no compactMetadata, no applied context edit, and no error. After that drop the prompt cache can freeze at the system-prompt prefix (`cache_read` a constant, `cache_creation` ≈ remaining context) so each trivial turn rewrites hundreds of thousands of tokens. Double-logged JSONL usage then inflates naive waste audits.

## Why Ullage

Ullage is the empty space in a cask. Score the cellar. Name the class or admit **gauged**. Idle word is **gauged** (a cask that is full and accounted for). When the level drops and no pour was chalked: **ullaged**. When the bung weeps on every turn: **thrashed**.

Verdicts: gauged, ullaged, thrashed, frozen, leaked, rewritten, doubled, healed, silent, bunged.

The desk gauges two new facts: (1) a partial context drop with no ticket (not a compact), and (2) a prefix-frozen cache thrash after that drop. It also flags double-logged usage so the waste number is honest. It does not claim the cache-key root cause.

Weighted waste (as used in #90509): `input×1 + cache_read×0.1 + cache_creation×2 + output×5`.
