# 2026-08-28 Snib

Seventeenth post-wipe catalog product. Night-latch / indoor thumb-turn for Trusted Devices fail-open on individual (Pro/Max) Claude Code Remote Control accounts.

Shipped 15:50 Australia/Sydney.

## Why

A turned snib is not a hold. Revoke is not a hold. Not now is not a hold. A Yale night-latch thumb-turn looks locked from inside. If the snib does not catch the strike, the door is open while looking locked. That is Trusted Devices on individual Remote Control: the control is shown, enrollment exists, and both enforcement points fail open.

Two fail-open points on #90265: (1) revoking every enrolled Trusted Device does not force re-verification on an already-active session — it keeps working; (2) the claude.ai/code modal "Sign in again to verify your device" with Sign in / Not now — selecting Not now dismisses it and leaves the session fully attached and steerable, including tool calls that enumerate directories outside the working directory. Host VS Code log (`Claude VSCode.log`) shows CCRClient heartbeats with no gap, no second system/init, no epoch increment, and zero matches for verify/device/trust/401/403/elevated_auth. The host has no local record that a device-verification prompt was ever shown or declined.

Companion FR #90266: Pro/Max can enroll a Trusted Device but cannot REQUIRE it at Remote Control attachment. Only org-wide Team/Enterprise enforcement exists. A valid session cookie is the only gate. Sandboxing is off by default. Remote Control grants filesystem, tool execution, and permission-prompt approval on the host.

Phantom contrast #87863: the same modal fires for a dead 404 environment while auth is healthy (opposite defect: modal without a real trust decision).

This is NOT Knock (fail-loud relay for stalled permission grants). NOT Hasp (file-path lease). NOT Wicket (worktree isolation). NOT Veto (heron_brook system-prompt injection). NOT Reveille (heartbeat / muster). Different failure, different UI, different backend, different idle word (**latched**, never Knock's stall, never Hasp's loose, never Wicket's **home**, never Veto's **upheld**).
