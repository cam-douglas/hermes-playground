## Problem

A rendered fold is not a hold. Claude Code Desktop collapses assistant text written between tool calls under "Ran N commands". Users only reliably see the final text block of a turn. Mid-turn substantive answers (numbered steps, requested explanations) are silently hidden with no hint that collapsed prose exists. The model believes it answered; the user sees tool-call chrome and a fragment.

## Why Pleat

A pleat is a pressed fold in cloth. When the iron leaves it standing, the grain underneath disappears. Desktop leaves a rendered fold where the answer was. Score the cloth. Name the class or admit **flat**. Idle word is **flat** (pleat pressed open; prose visible). When mid-turn prose is collapsed under Ran N commands: **pleated**.

Verdicts: flat, pleated, buried, folded, swallowed, midturn, chrome, fragment, ghosted, aired.
