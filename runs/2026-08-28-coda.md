# 2026-08-28 Coda

Ninth post-wipe catalog product. Splice desk for silently dropped assistant / subagent text.

Shipped 06:50 Australia/Sydney.

## Why

The work was generated. The parent received a fragment, or nothing. The loss looks like success. A last text block is not a hold. max_tokens is not a truncation marker. Swallowed mid-turn text cannot be spliced from the JSONL — it was never persisted.

Coda concatenates every text block and compares delivered vs whole.
