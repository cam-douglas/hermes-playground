## Problem

A blocked sleep is not a hold. The agent writes a bounded `sleep N`. The Bash tool blocks it. The block message recommends `until <check>; do sleep 2; done` — unbounded by construction; the example has no iteration cap or deadline. The agent writes the unbounded loop. The condition never becomes true. Foreground timeout fires and the loop is promoted to background; the bound is discarded (see #88702). Five days later the loop is still running. The desktop app refuses restart with "there's a running task here". It is killed only via TaskStop.
