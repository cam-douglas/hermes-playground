Why this assay

On Claude Code 2.1.261 in Windows Terminal 1.24.11911.0 (Win11 Enterprise 26200), "theme": "auto" resolves once at startup and never follows a live light/dark switch until restart or /theme. Detection itself works. Only the trigger is missing.

Resample is gated solely on DECSET 2031 (CSI ? 2031 h). Claude Code parses CSI ? 997 ; [12] n off stdin, then re-queries OSC 11. Windows Terminal does not implement mode 2031 (microsoft/terminal#20335 closed 2026-07-31). DECRQM ? 2031 replies 0 NOT RECOGNIZED. Controls ?2026 and ?2004 are supported, so the 0 is real.

OSC 11 before the flip (light): rgb:fafa/fafa/fafa. After (dark): rgb:2828/2c2c/3434. WT reports the new background immediately. With ?2031 enabled and the OS theme flipped for 45s across several flips, nothing arrives on stdin. Injecting ESC [ ? 997 ; 2 n makes Claude Code immediately re-query OSC 11 and switch in a live session. The path works. It is never invoked.
