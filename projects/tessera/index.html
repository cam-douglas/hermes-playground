Thesis

Native macOS installer runs each Claude Code release from a version-named path. macOS TCC attributes grants to the executable path, so every release registers a new client. System Settings accumulates one permission row per release — bare version number labels — in App Management and Files & Folders. The updater deletes old binaries but leaves the tiles. Users cannot pry them off.
