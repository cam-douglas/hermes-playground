Thesis

Windows Bash tool transports the whole command through argv to MSYS2 bash -c. Commands over ~8,203 chars are silently truncated; bash reports a bogus syntax error at a mid-payload apostrophe. Doubled backslashes collapse at any size (295 B). Both disappear on bash -s. Documented stack buffer: 8,192 (msys2-runtime#178). Symptom 2 cause is unconfirmed inference.
