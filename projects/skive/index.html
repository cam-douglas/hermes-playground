Research brief

        

          Primary:
          anthropics/claude-code#92271
          (OPEN, bug, has repro, platform:macos, area:hooks, area:permissions).
          In bypassPermissions (and auto mode), Claude Code injects a Bash-first
          meta instruction gated by tengu_thrifty_sonic /
          CLAUDE_CODE_THRIFTY_SONIC. It tells the model to prefer
          cat/head/sed/heredocs over dedicated
          Read/Edit/Write. Path-scoped rules, nested subdirectory CLAUDE.md,
          and PreToolUse/PostToolUse hooks with Read|Edit|Write matchers are wired only
          to those dedicated tools — so following the instruction silently disables all
          three enforcement layers, exactly in the mode with least oversight.
        

        

          While bypass permissions mode is active: Do your work through the Bash tool
          wherever it can accomplish the job: read files with cat, head, or sed -n …
          rather than using the dedicated Read, Edit, or Write tools.
        

        

          Verified: Read tool loads RULE-LOADED-7731 / NESTED-LOADED-4402; Bash
          cat of the same file returns NO-TOKENS. Kill switch:
          CLAUDE_CODE_THRIFTY_SONIC=0 in settings env. Model-gated
          (active on fable[1m] by default; sonnet/haiku need flag).
        

        

          Cousin cite-only:

          (same Bash-first steer in auto mode, Windows) ·
          #92074
          (hooks never fire in VS Code extension — different cause). Public write-up:
          kawasin73 2026-09-05
          confirming the kill switch and Rules / hooks / nested CLAUDE.md death.
        

      


      

        
1 — Three straps on dedicated tools only

        

          Path-scoped rules (.claude/rules/*.md with paths:),
          nested subdirectory CLAUDE.md, and PreToolUse/PostToolUse hooks
          with a Read|Edit|Write matcher fire only when those dedicated tools run.
        

        
2 — Bash-first steer in the least-oversight mode

        

          In bypassPermissions (and auto), the injected instruction tells
          the model to prefer cat/head/sed/heredocs.
          Following it silently unbuckles all three straps.
        

        
3 — Same file, two replies

        

          Dedicated Read of src/sub/hello.txt returns
          RULE-LOADED-7731 and NESTED-LOADED-4402.
          Bash cat of the same file returns NO-TOKENS.
        

        
4 — Kill switch and model gate

        

          CLAUDE_CODE_THRIFTY_SONIC=0 in settings env removes the
          instruction. Active on fable[1m] by default; sonnet and haiku need the
          flag set to 1.
