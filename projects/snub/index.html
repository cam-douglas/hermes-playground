1 — 512-byte cliff, 64 KB assumption

        

          bash 5.1 changed heredocs from temp files to pipes; temp-file fallback
          only at ≥65536 bytes (Linux PIPE_BUF). macOS pipe capacity is 512
          (getconf PIPE_BUF / → 512). Writer fills the pipe and
          blocks before forking the drain child → deadlock. Only total body
          size matters.
        

        
2 — Broken range is bounded on both sides

        

          Bodies ≤512 bytes fit the pipe. Bodies ≥64 KB take the temp-file
          path. Mid-size 513–65535 hangs. Bisect via Bash tool: 377 B OK,
          496 B OK, ~600 B HANGS, ~960 B / 2 KB / 4 KB / 5 KB HANGS; 100 KB OK.
        

        
3 — Two product behaviours turn an upstream bug into data loss

        

          (1) The Bash tool uses PATH-resolved bash, so Homebrew 5.1+ is picked
          instead of unaffected /bin/bash 3.2.57.
          (2) The redirect truncates the target before the heredoc
          body is known to have arrived — a 120s stall plus a file left at 0 bytes.
        

        
4 — Auto mode maximises exposure

        

          Auto mode / bypass-permissions steer the model to prefer
          cat <<EOF over the Write tool (#92178, #88041,
          #90599, #88791). Reporter emptied a ~2 KB mix.exs;
          COMPLETED never printed after the heredoc.
        

        
Expected (from the issue — checklist, not implemented here)

        

          Don’t destroy the target on a failed write. Invoke
          /bin/bash explicitly. Fail fast with a diagnostic.
          Reconsider auto-mode heredoc guidance. Workaround
          shopt -s compat44 restores pre-5.1 temp-file heredocs
          (undocumented side effect).
        

        
Likely path (NON-BINDING)

        

          The desk should make the 512-byte pipe cliff and truncate-before-body
          failure visceral. Discard if evidence disagrees. Do not claim unseen source.
        

        
Environment

        

          Claude Code 2.1.260 (Claude Desktop, Code tab) · macOS 26.5.2 arm64.
          /opt/homebrew/bin/bash 5.3.15 affected (5.3.9 in prior
          reports); /bin/bash 3.2.57 not affected. OPEN, bug, has
          repro, platform:macos, area:bash. Fixtures fictionalize
          /tmp/probe.txt and $HOME/<demo-home>/mix.exs.
