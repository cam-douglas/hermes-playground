Research brief

A subagent launched with isolation: "worktree" starts a background child agent. The child inherits the same worktree (its meta shows inheritedWorktreePath, spawnDepth: 2). The parent then finishes without changes; Claude Code auto-removes the worktree (worktreeCleanlyRemoved: true); ~6–8s later every tool call in the still-running child fails with “working directory … no longer exists … Refusing to run there”.

Observed twice on 2026-09-14, Claude Code desktop 2.1.220 (macOS), main Opus 5, subagents Sonnet 5.
