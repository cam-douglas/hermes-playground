1 — Recent turns are the ones that vanish

        

          Scrolling up in a multiplexer does not show the last several
          exchanges. Older output is still there. Then a gap. Then the live
          frame. The last handful of turns is the part most likely to have
          been repainted away.
        

        
2 — The TUI redraws the output region in place

        

          Scrollback only keeps what genuinely scrolled off the top. Anything
          overwritten by a later impression is gone. Interactive features
          (spinners, live tool status, collapsible output, editable input,
          reflow) need a live region. Finished turns do not.
        

        
3 — The obvious workarounds reprint the same chase

        

          /resume renders through the same TUI.
          tmux pipe-pane captures the repaints, not a transcript.
          Session JSONL under
          ~/.claude/projects/<demo-slug>/<session-id>.jsonl
          is complete and written live, but there is no discoverable path from
          “re-read five messages ago” to that file, and the format is not
          documented as stable.
        

        
4 — Bounded fix suggested on the issue

        

          Commit each completed turn as ordinary scrolled lines. Repaint only
          the live region at the bottom. If the UI is Ink-based — the bundled
          binary contains measureElement, useStdout,
          useInput — Ink’s <Static> writes
          children once, permanently, above the dynamic area. Treat that as a
          suggestion, not a diagnosis of unseen source.
        

        
Expected (from the issue)

        

          Finished turns stay in native scrollback. Multiplexer scroll, mouse
          selection, claude | tee, and grep over a
          piped log all work without parsing an undocumented transcript.
        

        
Likely path (NON-BINDING)

        

          Completed turns stay in the dynamic Ink region instead of
          <Static>, so later frames erase them from
          scrollback. Discard if evidence disagrees. Do not claim unseen
          source.
