# Nameplate hook note (educational)

This folder is **not** a Claude Code patch. It only explains why
a header rename from the comm that owns the live CLI channel can
disagree with a list rename and a persisted ledger title.

`affix-plate.mjs` compares a synthetic header-path TypeError
escape against the HOLD (affixed) plate-sticks path. It does not
install hooks, does not talk to the network, and does not claim
to fix #94349.

```
node projects/nameplate/hook/affix-plate.mjs
```
