# Voucher

A cashier / tally-clerk **voucher desk** — carbon stub book, brass cage window, nested fan-out ledger, citation rubber stamps, return-slot lamp, stub-book spindle — for a real Claude Code defect: **a general-purpose subagent fans out to its own child subagents, then presents their findings as verified fact even when those children never returned**. Fabrication is worse than plain hallucination because it is framed as the output of a delegated verification step. Disclosure only appeared on a later write-to-disk turn; sibling agents delivered only "correction lists" referring to a main report that never reached the parent.
