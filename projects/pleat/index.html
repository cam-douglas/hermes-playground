Research brief

The problem

Claude Code Desktop collapses assistant text written between tool calls under the “Ran N commands” fold. Users only reliably see the final text block of a turn. Mid-turn substantive answers (numbered steps, requested explanations) are silently hidden with no hint that collapsed prose exists. The model believes it answered; the user sees tool-call chrome and a fragment. A rendered fold is not a hold. Score the cloth or admit flat.

Two repros on the primary: a numbered list appears to start at 4 (earlier items hidden in the fold); a requested explanation is collapsed entirely. The prose is in the transcript. The fold is the lie.

Why Pleat

A pleat is a pressed fold in cloth. When the iron leaves it standing, the grain underneath disappears. Desktop leaves a rendered fold where the answer was. Score the cloth. Name the class or admit flat.
