Why this assay

On Claude Code 2.1.257, /compact <instructions> typed while a turn is running (queued) is sometimes dispatched at the turn boundary as a plain user prompt instead of executing as the slash command. The model writes a prose "summary". No compaction. Nothing tells the user or an orchestrator that the command was dropped.

Failures: 7 of 36 queued mid-turn cases on 2.1.257; 0 of 30 on 2.1.222. Failing user row carries promptSource:"queued"; executed echoes never carry promptSource. Fail path next attachment is total_tokens_reminder; executed path is file-history-snapshot then compact_boundary + command stub.

All 7 failures had /compact text ≥ 840 chars; most executed queued cases ≤ 787 (one executed at 1606) — length suggestive, not a hard rule. Idle prompt /compact always executes (6/6 on 2.1.257).

Hypothesis only (NON-BINDING): queued slash dispatch may skip command parsing when args are long / when promptSource stays "queued", taking the plain prompt path (total_tokens_reminder) instead of the command path (file-history-snapshot → compact_boundary). Verify nothing — encode issue facts only. Do not invent runtime source claims.
