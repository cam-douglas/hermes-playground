Research brief

Voice dictation in the desktop app drops words throughout the recording — output is fragments, not a transcript. Loss is continuous: beginning, middle, and end. Isolated recognized chunks remain; connecting speech is missing. Every dictated prompt has to be rewritten by hand.

Claude Code desktop app v2.1.237; macOS Darwin 25.6.0; built-in MacBook Pro microphone, 48 kHz, input ~57%. Reproduces in en AND de. BOTH hold and tap mode. Same machine, same microphone, same spoken sentence: ChatGPT dictation is essentially verbatim; Claude Code returns fragments. Switching hold to tap makes no observable difference, so this is not only documented hold-mode warmup dropping the first words. 15s silence auto-stop and the 2 minute maximum compound (tracked separately in #74534).
