Published walk · #93687

          

            Desktop Scheduled Tasks, Windows. Docs say that on app start or
            wake, Desktop checks missed runs in the last seven days and starts
            exactly one catch-up for the most recently missed time. For a
            day-restricted cron such as 0 19 * * 1 (Monday-only)
            or 45 18 * * 3 (Wednesday-only), that missed time
            should itself fall on the correct weekday. Five tasks with
            different weekly schedules (Friday-only, Wednesday-only ×2,
            Monday-only, Thursday-only) all fired within about four minutes
            (~12:15–12:19 AM local) on a Friday. list_task_runs
            mixes correctly-timed runs with sporadic wrong-day fires
            (Thursday-only on Sunday and Friday; Wednesday-only on Friday
            and Thursday). Misfires report status: succeeded.
            Schemas expose only enabled / cronExpression / fireAt / prompt /
            title / description / notifyOnCompletion — no catch-up toggle.
            Prompt-level day guards are the present mitigation. Outbound
            side effects (Gmail drafts, Jira, git commits) can duplicate.
