Deadeye

Standing-rigging / lignum-vitae deadeye. A deadeye that should reeve the PreToolUse hook lanyard against the mast (stable project root / $CLAUDE_PROJECT_DIR), but a relative hook command path is resolved against the Bash tool's mutable, cd-able working directory. After any cd some/subdirectory && ..., hook spawn fails ENOENT on <drifted_cwd>/scripts/... — and because PreToolUse runs before the user command, every subsequent Bash call (including pwd, echo, corrective cd) fails the same way. Session Bash is permanently deadlocked. Subagents without worktree isolation inherit the broken cwd; isolation: "worktree" resets cwd and escapes. A deadeye that reeves the hook lanyard against the moving block is not standing rigging — it is foul. Score the reeve or admit the Bash already seized.
