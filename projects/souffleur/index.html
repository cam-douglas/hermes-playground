Research brief

Blind user relies entirely on VoiceOver. Since the Claude desktop app updated on 11 September 2026 to version 1.52386.3 (Electron 44.2.0), VoiceOver no longer echoes typed characters in the prompt box after switching to another app and returning to Claude.

The rest of VoiceOver still works: VO navigation, headings and controls, Claude replies, and the “finished responding” announcement. Only typing echo is lost, so many typing mistakes follow. Quit+reopen restores typing echo until the next app switch. This never happened before this update (regression). Typing echo still works in Chrome, Terminal, and other Electron apps on the same Mac — specific to this Claude desktop version. Affects regular chat and Cowork sessions.

Workarounds that FAILED: VO Shift Down/Up interact cycle; VO off/on (Cmd F5×2); Escape leave + VO Space re-enter. Only quit+relaunch works; the fault returns on the next app switch. Environment: macOS 26.5.2 (build 25F84), Claude Max; form Platform/Terminal fields N/A. Resembles the long-standing Chromium/Electron VoiceOver typing-echo fault (electron/electron#13203) but newly triggered by app switch after this app version — possibly an Electron/Chromium focus-restore change. Related VoiceOver report (cousin cite-only): #87977 (navigation jumps — different symptom).
