            Claude Code 2.1.267 native Linux. Terminal: Black Box (VTE 0.84,
            XTVERSION reply VTE(8401)),
            TERM=xterm-256color, no tmux/zellij. Once the
            conversation fills the screen, the TUI stops 2–3 rows short of
            the window bottom. The empty rows sit below the last line of the
            bottom block (the auto-mode hint, or the remote-control indicator
            when it is shown). Sometimes one more empty row is added during a
            session. The rows stay empty at all times. On macOS with the same
            setup (Claude Code 2.1.268 on kitty, iTerm2, Terminal.app) the
            bottom block ends on the last row. Debug log prints
            DECSTBM: enabled (TMUX unset, ZELLIJ unset,
            TERM_PROGRAM=Black Box). The renderer is on via
            CLAUDE_CODE_DECSTBM or the remote gate
            tengu_marlin_porch. The env var is unset, so the gate
            is on. There is no local toggle to turn the renderer off.
            Terminal padding, statusLine variants, env pollution, and
            LINES/COLUMNS were already ruled out.
