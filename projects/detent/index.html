Research brief

Since 2.1.271, left clicking a session row in the claude agents list no longer opens that session. Nothing happens on click. Keyboard navigation (arrows + Enter) still works. Rolling back to 2.1.270 restores clicking immediately. 2.1.272 is still affected.

Environment: Claude Code broken in 2.1.271 and 2.1.272, works in 2.1.270. Native installer. macOS Darwin 25.5.0. Apple Terminal.app, TERM=xterm-256color, Use Option as Meta key enabled. TUI mode fullscreen via "tui": "fullscreen" in ~/.claude/settings.json. Steps: have background sessions; run claude agents; left click any session row (Pinned, Ready for review, Working, Completed). Expected: the clicked session opens. Actual: the click is ignored.

Primary: anthropics/claude-code#94565 (OPEN). Labels: bug, has repro, platform:macos, area:tui, regression, area:agent-view.
