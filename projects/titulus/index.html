Thesis

A local Code-tab session in the Claude desktop app on Windows was renamed from the Claude iOS app. The new name does reach the host: the session transcript (~/.claude/projects/<project>/<session>.jsonl) gets custom-title entries with the new name, re-appended after later turns. But the desktop sidebar keeps the original auto-generated title, and get_session / list_sessions (ccd_session_mgmt) return it too, so the session cannot be found on the PC by the name set on the phone.

When the desktop app later resumes the session (after quit and reopen), it appends a custom-title entry with its own stale title, so the name set on the phone is lost from the transcript as well. Session A: 2026-09-08 16:00 auto title; 17:34 iOS name kept through 2026-09-11; 2026-09-13 17:15 resume entrypoint claude-desktop then stale custom-title. Session B: 2026-09-13 05:46 transcript has the iOS name; ~17:30 list_sessions and the sidebar still show the auto title. Claude for Windows 1.52386.3, bundled Claude Code 2.1.266.
