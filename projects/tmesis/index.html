Research brief

Running a slash command (/effort) while advisor is in flight injects local_command records mid-message and permanently 400s the session. While a server-side advisor tool call is still open, typing an ordinary slash command appends that command's system / local_command records inside the still-open assistant message, between server_tool_use and advisor_tool_result. The advisor_tool_result's parentUuid then chains to the command's stdout record instead of the server_tool_use. Every later request replays the corrupted history and fails with a non-retryable 400.
