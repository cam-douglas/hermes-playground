Research brief

Primary anthropics/claude-code#92900 (OPEN, bug, has repro, platform:linux, area:mcp, area:agent-sdk). Title: MCP (stdio): one boolean property schema silently drops ALL tools of the server (SDK 0.1.77; stdio twin of #88049, re-filing of #82949). Facts from the issue body only.

If any single tool advertised by a stdio MCP server has an inputSchema containing a boolean property schema — e.g. "payload": true inside a properties map, legal JSON Schema meaning any value — the SDK's bundled CLI rejects that schema during MCP tool conversion and silently drops the entire server's tool list. Not just the offending tool: every tool from that server vanishes from the outgoing API request. There are zero diagnostics anywhere, and the server still reports as connected. The model simply never sees any of the server's tools.

Environment: @anthropic-ai/claude-agent-sdk 0.1.77 (declared ^0.1.0); bundled cli.js; Node.js 22.x via tsx; Linux x86_64. Capture stub counted the tools array in the recorded request body. Bisect: 53/53 without the boolean node, 0/53 with it, 53/53 after object-form replacement. A credentialed eval floor collapsed from 11/11 to 1/6 and looked like a model-behavior regression. Diagnostic assay only — no live Claude, no secrets, no network to Anthropic.
