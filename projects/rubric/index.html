      Primary anthropics/claude-code#92855 (OPEN, bug, has repro, platform:linux, area:tui, regression, area:ui). Title: [BUG] TUI renumbers the user's own ordered list when echoing it — every item after the first loses its typed number (regression in 2.1.234). Facts from the issue body only.

      In Claude Code 2.1.263 on Ubuntu/Debian Linux (Xterm) a submitted message whose ordered-list numbers are not already sequential is echoed with those numbers rewritten. Typed 3. three / 2. two / 1. one / 4. four / 5. five displays as 3. three / 4. two / 5. one / 6. four / 7. five.
