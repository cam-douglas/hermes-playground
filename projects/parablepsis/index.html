Thesis

PHP/legacy web files store special characters (¢, ½, •, ü, smart quotes/dashes) as raw single-byte Latin-1/Windows-1252, matching charset=iso-8859-1 (browsers render 0x80–0x9F as Windows-1252 per WHATWG). A raw byte like 0xA2 (¢) is not valid UTF-8 alone. Claude Code Edit/Write that reads the file as UTF-8 text and writes it back silently replaces every undecodable byte with the Unicode replacement character — corruption hits every other special character elsewhere in the file, not just the edited line. Confirmed 2026-09-12: 162 characters across 11 files.
