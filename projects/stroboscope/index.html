Why this assay

In the Claude Code desktop app (Code tab) 1.46388.4 on Windows 11 Enterprise 10.0.26200 with Windows PowerShell, the Terminal panel flickers — opens then closes — on every Bash/PowerShell tool call and steals keyboard focus from the chat input.

Expected: the panel stays in whatever state the user left it, or updates in place without taking keyboard focus. Typing in chat should never be interrupted by a tool call. Actual: focus jumps; keystrokes during the flicker are lost or misdirected.

Ruled out: hooks in ~/.claude/settings.json (none), custom keybindings (file absent), desktop config.json (only terminalCliPowerShellPath + layout — no auto-open or auto-focus setting), leaving Terminal already docked open (still flickers). run_in_background: true is worse (two flickers). File read/write/search produce no flicker.
