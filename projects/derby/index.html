          Primary
          anthropics/claude-code#93197
          (OPEN, bug, has repro, platform:macos, area:packaging).
          Title:
          Auto-updater: two concurrent sessions race on the npm-global install and delete the claude package (dangling symlink, 'command not found').
          Facts from the issue body only.
        

        

          Claude Code 2.1.266, npm-global install under Homebrew node;
          npm 11.12.1; Node 25.9.0; macOS 26.x (Darwin 25.6.0), Apple
          Silicon. Two sessions launched ~90 ms apart (one interactive
          in one project dir, one in another dir with a different
          CLAUDE_CONFIG_DIR). Each started
          npm install --global @anthropic-ai/claude-code@2.1.266.
          Both retired the live package to
          /opt/homebrew/lib/node_modules/@anthropic-ai/.claude-code-2DTsDk1V.
        

        

          One run ended error process terminated / error signal SIGHUP / exit 1;
          the other logged exit 0 / info ok. Afterward
          /opt/homebrew/lib/node_modules/@anthropic-ai/ was
          empty and /opt/homebrew/bin/claude was a dangling
          symlink, so every new shell got claude: command not found
          until a manual reinstall. Expected: take a lock, or skip when
          another update is already in flight.
        

        

          Evidence: 14_02_34_904Z-debug-0.log and
          14_02_34_992Z-debug-0.log; preceding
