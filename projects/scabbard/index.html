Primary anthropics/claude-code#92820 (OPEN, bug, area:agents, platform:windows). Title: Custom subagents that declare Bash in frontmatter never receive it (no config can restore it). Filed 2026-09-08T10:07:10Z by RachidSo. No comments. Facts from the issue body only.

A custom subagent defined in .claude/agents/*.md with Bash listed in tools: is invoked with that tool silently omitted. Every other declared tool (Read, Write, Edit, Grep, Glob) is granted correctly. No error, warning, or denial. The subagent reports (and behaves as if) it never had the tool. Process-dependent custom types — git diff, tests, lint — are non-functional as native types with no config workaround.

Impact in the reporter's six-agent QA pipeline: 2/6 completely non-functional, 1/6 degrades, 3/6 unaffected. Workaround: orchestrator pre-computes shell work, or fall back to general-purpose (receives *).
