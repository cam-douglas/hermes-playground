    • Pending map keyed by PID in the single shared ~/.claude.json. Every concurrent session adds an entry at startup and removes it ~10s later.
    • Burst start+settle = read-modify-write races; lost updates leave entries for dead PIDs. Next launch reads those as crashed boots.
    • Strikes only clear on a healthy settle. Signal-driven exit settles as withdrawn: removes that PID's entry but preserves the strike counter.
    • PID reuse is a false positive: pid === ownPid counted as a strike without startedAt vs process start.
