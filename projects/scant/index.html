The problem

On Windows Desktop the Bash tool's shell snapshot is silently truncated at ~7.2 KB. The cut lands mid-export PATH='...' so the quote never closes. Every later Bash call fails unexpected EOF. A written shell snapshot is not a hold. Score the board or admit fit.

Every snapshot in ~/.claude/shell-snapshots/ ends at 7187–7195 bytes, always mid-PATH, no closing quote, no trailing newline. Truncation size + wrapper overhead ≈ 8191 — the Windows cmd.exe command-line length limit. Repairing the file on disk does not recover the running session. Deleting the snapshot makes commands silently no-op.
