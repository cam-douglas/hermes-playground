Open Unseen Ink Read the product brief

Research signal

Hidden-glyph strippers and C2PA / watermark cleaners are the crowded object this week. They delete marks from text you already own. Reviewers still need to see inbound ZWSP, bidi trojans, and tag characters before an agent or a merge sees them.

Problem

A skill file or PR description can look like a PNG download and a short policy while the bytes hide user_exe, zero-width gaps, and a tag-encoded second string.

Prototype scope

Paste or drop inbound text, highlight hidden codepoints in place, and list codepoint / name / count / why. Seeing is the job. No silent strip-by-default, no skill-clash clone, no fluency or inventory board.
