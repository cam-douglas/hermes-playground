Today’s featured bet is Ghost Briefs: a human-only map of which shipped subsystems still have a named person who can brief them. GitHub this week is crowded with harnesses and skill packs; this prototype targets the quieter gap — fluency after the agent already merged.

Open Ghost Briefs Read the product brief

Research signal

Faros Acceleration Whiplash and Storey’s Triple Debt point at the same hole: more finished work, more incidents, more cognitive and intent debt. The missing shippable thing is a human brief map, not another agent harness.

Problem

Teams can name the last model that touched a subsystem and still be unable to name a person who can explain it in ninety seconds.

Prototype scope

Vote fluency, file a three-sentence brief, rank ghosts and orphans, persist locally, export JSON. No chat, no handoff console, no inventory.
